Desk Calculator

A simple, stylish calculator built with just HTML, CSS, and vanilla JavaScript — no frameworks.

Features
Basic operations: add, subtract, multiply, divide
Percent (%) and negate (±) buttons
Keyboard support (numbers, + - * /, Enter for =, Esc to clear)
Retro desk-calculator look with an LCD-style display
How to run

Just open index.html directly in your browser — no build step or installation needed.

Files
index.html — structure
style.css — styling
script.js — calculator logic
